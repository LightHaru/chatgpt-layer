# 1.1.0

ChatGPT Layer 1.1.0 is a fork release of Codex++ 1.0.0.

## Highlights

- User-facing name is ChatGPT Layer. Commands: `chatgpt-layer`, `cgl`, `codexplusplus`.
- Windows prefers `ChatGPT.exe` over the stub `Codex.exe`.
- Store package discovery uses the `OpenAI.Codex` family name.
- Data paths stay `%APPDATA%/codex-plusplus` so existing tweaks keep working.
- Unofficial. Not affiliated with OpenAI. Fork of Bennett Codex++.
