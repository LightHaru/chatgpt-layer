# 1.1.0

First ChatGPT Layer release. Fork of [Codex++ 1.0.0](https://github.com/b-nnett/codex-plusplus) after upstream archived.

Unofficial. Not affiliated with OpenAI.

## Highlights

- User-facing name is **ChatGPT Layer**. Commands: `chatgpt-layer`, `cgl`, `codexplusplus`.
- Windows prefers `ChatGPT.exe` over the stub `Codex.exe`.
- Store discovery uses the `OpenAI.Codex` package family. Mirror path is `%LOCALAPPDATA%/codex-plusplus/store-apps/OpenAI.Codex/`.
- Data paths stay `%APPDATA%/codex-plusplus` so existing tweaks (including Codex Accounts) keep working.
- Settings sidebar group is ChatGPT Layer. Shortcuts: **ChatGPT Layer** plus the old `Codex++.lnk`.

## Install (Windows)

Node 20+, then:

```powershell
irm https://raw.githubusercontent.com/LightHaru/chatgpt-layer/main/install.ps1 | iex
```

Launch the **ChatGPT Layer** shortcut, not the Store icon. After a Store update, quit `ChatGPT.exe` and run `chatgpt-layer repair`.
